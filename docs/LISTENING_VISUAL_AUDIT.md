Скрипт сопоставляет Part/group/original_source_image/question bindings; отдельно проверены option/answer-bank visual refs — текущих пропущенных ссылок нет.

Проверены 388 уникальных пар изображений, одновременно выдаваемых resolver. SHA ищет точные байтовые дубли; pHash — близкие изображения; ORB + RANSAC homography и согласованность тёмных пикселей подтверждают crop containment. Ещё 18 глобальных near-hash кандидатов не считаются отдельными UI-дефектами без совместного вывода/содержательного подтверждения.

OCR выполнен локальным Tesseract по 590 изображениям, диапазоны явно распознаны у 445. Единственное изображение без OCR-текста (`Test_1_Section_3_Modular_Courses_Summary.png`, C05 T1 P3) просмотрено: текст Q26–30 виден, изображение не пустое. ## Системные причины

### R1 — IMPORTER: crop и оригинал становятся равноправными материалами

[Assets.add](../backend/scripts/listening_dataset/importer.py#L464) дедуплицирует по SHA байтов и копирует исходные байты; семантически одинаковые crop/full-page закономерно имеют разные IDs. [Сбор selected](../backend/scripts/listening_dataset/importer.py#L1156) объединяет совпадение имени, Test/Part и PDF page, не выбирая каноническую версию. [Сохранение Part](../backend/scripts/listening_dataset/importer.py#L1212) и [передача selected каждой группе](../backend/scripts/listening_dataset/importer.py#L1220) разносят весь набор. [Group supporting_assets](../backend/scripts/listening_dataset/importer.py#L767), [question visual_binding](../backend/scripts/listening_dataset/importer.py#L705) и [original_source_image](../backend/scripts/listening_dataset/importer.py#L736) могут содержать те же страницы. Пример: C05 T1 P1 Dreamtime crop + PDF011; C09 T2 P2 три версии карты дают три повторяющиеся пары.

### R2 — RESOLVER: ID-only union и широкий Part fallback

[source-material.ts:8](../web/src/features/listening/source-material.ts#L8) соединяет group/block/question пути и Set устраняет только одинаковые IDs. [Строка 13](../web/src/features/listening/source-material.ts#L13) при пустом direct берёт все part.supporting_assets, без отбора по диапазону/роли. Поэтому fallback предотвращает отсутствие страниц, но также показывает ранее подготовленные crop и PDF одновременно. [WorkspaceQuestions:63](../web/src/features/listening/workspace-questions.tsx#L63) без дополнительной фильтрации выводит весь результат. **414** групп используют этот fallback; это охват механизма, не 414 ошибок. Пример C05 T1 P1: Q1–4 получает также страницы более поздних вопросов.

### R3 — IMPORTER + RESOLVER: порядок определяется перечислением файлов

[Importer:1082](../backend/scripts/listening_dataset/importer.py#L1082) лексикографически перечисляет пути; selected сохраняет этот порядок. В sourceMaterial нет сортировки по вопросу. Из-за названий Map/Activities/PDF изображения Q16–20 или Q15–20 могут оказаться перед Q11–15/14. Подтверждены девять пар ниже. Часть — возврат к раннему вопросу после уже показанной полной страницы: это инверсия списка, не обязательно отсутствие ранних вопросов в начале Part.

### R4 — DATA / IMPORTER: ошибочная исходная метка становится привязкой

В C18 T2 `Test_2_Part_4_PDF_035.png` фактически содержит Q6–10. [Разбор имени:1098](../backend/scripts/listening_dataset/importer.py#L1098) назначает Part 4, а выбор по PDF page дополнительно сохраняет корректный Part 1. [Добавление associations:1190](../backend/scripts/listening_dataset/importer.py#L1190) закрепляет обе связи. Ошибка имени/привязки доказана пикселями; название файла само по себе не доказывает, что правильный P1 ошибочен.

### R5 — DATA: подготовленные crop уже содержат срезанный текст; UI риски отдельно

Срезы видны в исходных публичных файлах. Importer Assets.add в обычном пути не режет картинки, поэтому нельзя приписать физическую обрезку этой функции: место/инструмент подготовки исходных crop не установлены. Примеры C05 T1 P1, C18 T3 P1, C21 T2 P3; таблица ниже содержит 26 подтверждений.

[listening.module.css](../web/src/features/listening/listening.module.css#L1): `.imageButton img` использует width:100%, height:auto; object-fit:cover и фиксированного среза высоты нет. overflow:hidden у кнопки скругляет углы, но не объясняет отсутствующие слова в исходных пикселях. [questions.tsx:9](../web/src/features/listening/questions.tsx#L9) не резервирует геометрию до blob-загрузки и не сбрасывает src/error при смене идентичности; [workspace CSS](../web/src/features/listening/workspace.module.css#L15) отключает overflow anchoring. U001/U002 — подозрения, не воспроизведённые дефекты. [materialKey:40](../web/src/features/listening/workspace-questions.tsx#L40) сбрасывает source scroll при смене assets/bank/lines; пассивный scroll сам не переключает группу. Общие материалы не обязаны меняться при каждом переходе вопроса — это не ошибка само по себе.

Exam [pages.tsx:37](../web/src/features/listening/pages.tsx#L37) и Review [review.tsx:87](../web/src/features/listening/review.tsx#L87) используют один WorkspaceQuestions и Asset. Разных resolver для них нет; подтверждённые проблемы данных распространяются на оба режима. Backend AI и другие запрещённые подсистемы не исследовались.
